# API Loja de Roupas 👕

Minha primeira API REST desenvolvida em **Java 21** com **Spring Boot**.

## 🚀 Tecnologias
- JDK 21
- Spring Boot 3
- Spring Data JPA
- PostgreSQL
- Lombok

## 🛠️ Funcionalidades (CRUD)
- [x] Cadastro de produtos
- [x] Listagem de produtos
- [x] Atualização de dados
- [x] Remoção de produtos
